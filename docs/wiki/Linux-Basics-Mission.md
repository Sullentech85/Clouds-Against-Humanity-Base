# Linux Basics Mission (Stub)

## Goal
Become comfortable with core commands, permissions, and basic navigation before moving to cloud stages.

## Tools
See the Book of Secret Knowledge (Layer 1) for shell, permissions, and process tools.

## Mission
1. On a Linux system you control, create a test user and directory.
2. Demonstrate read/write/execute permission changes and what breaks.
3. Take a snapshot or note how you would restore.
4. Write a short markdown note of what you did and what surprised you.

## Deliverable
A markdown file with commands used and observations.
