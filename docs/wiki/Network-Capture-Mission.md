# Network Capture Mission (Stub)

## Goal
Capture and annotate one full request path (DNS → TCP → TLS → HTTP) on traffic you generate.

## Tools
See the Book of Secret Knowledge (Layer 2) for Wireshark/tshark and related utilities.

## Mission
1. Start a capture on an interface you control.
2. Generate a simple HTTPS request.
3. Identify and annotate the DNS, TCP handshake, TLS, and HTTP portions.
4. Save the capture (or screenshots) and a short explanation.

## Deliverable
Annotated capture notes or a short write-up.
