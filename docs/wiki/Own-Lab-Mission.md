# Own Lab Mission (Stub)

## Goal
Run a deliberately vulnerable application you control, find one issue, document it, then destroy the environment.

## Example
Juice Shop (or equivalent) via Docker/Portainer on a host you own.

## Mission
1. Deploy the lab on a private path or local machine.
2. Use browser tools or Burp to find one vulnerability.
3. Document the finding and steps.
4. Tear the environment down.

## Deliverable
Short lab report + proof of teardown.
