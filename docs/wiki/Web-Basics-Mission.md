# Web Basics Mission (Stub)

## Goal
Bridge from “I can reach a host” to understanding HTTP, sessions, and cookies.

## Tools
See the Book of Secret Knowledge (Layer 3) for browser developer tools and web-related entries.  
PortSwigger Web Security Academy is a strong free external companion.

## Mission
1. Open browser developer tools on a site you control or a public lab.
2. Observe one full request/response cycle.
3. Identify cookies, headers, and status codes.
4. Write a short note mapping what you saw.

## Deliverable
Markdown notes or annotated screenshots.
