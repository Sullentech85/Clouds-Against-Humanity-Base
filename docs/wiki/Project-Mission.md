# Project Mission (Stub)

## Goal
Turn a one-liner or function from the Book into a small working script and sample report against systems you own.

## Examples
- Log parser that outputs a short summary
- Port-check report generator
- Simple health-check script

## Mission
1. Choose one small automation idea.
2. Write a working script.
3. Run it against a system you control.
4. Document the script and sample output.

## Deliverable
Script + short write-up.
