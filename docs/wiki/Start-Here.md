# Start Here

The existing stages assume a learner who already has basic Linux, networking, and web foundations.

If you are earlier in the path, use this page first.

## Companion Reference
The companion reference library is the Book of Secret Knowledge:  
https://github.com/Sullentech85/Sullen-the-book-of-secret-knowledge

It now contains a **6-Layer Learning Path** index near the top that groups tools by layer.

## Recommended Sequence
1. Layer 1 — Linux basics (see Book + the Linux mission stub in this wiki)
2. Layer 2 — Networking capture mission (see Book + the Networking mission stub)
3. External guided path (TryHackMe Pre-Security or Cybersecurity 101) before advanced cloud stages
4. Return to the existing Clouds stages once the foundations are comfortable
